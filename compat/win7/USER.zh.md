# CSGClaw 0.9.0 Win7 桌面版

安装版：双击名称以 `Setup.exe` 结尾的安装包，按向导完成安装，再从桌面或开始菜单打开 `CSGClaw Win7`。
程序和全部依赖会自动安装到当前用户目录，不需要管理员权限。
安装包以版本号、构建日期和源码 commit 命名，已安装时会自动沿用原目录升级，不需要先卸载。
相同版本可修复安装，降级到旧构建时会要求确认。
升级保留登录、配置、聊天记录和工作区；升级失败会尝试恢复原版。
若安装被意外结束，再次运行安装包即可恢复并重试；不要自行删除安装目录旁的升级备份目录。
需要覆盖安装或卸载时，先从托盘菜单退出 CSGClaw。
可在 Windows 控制面板的“程序和功能”中卸载，也可使用开始菜单中的卸载入口。
卸载只移除安装的程序文件，保留账号、配置、会话和工作区数据。

不需要手动启动 Go 服务，也不需要打开外部浏览器。
交付文件为完整安装包，不需要手动解压，也不要单独复制安装目录中的 `CSGClaw.exe`。

首次使用按界面配置模型服务。
模型、第三方账户及外部工具仍需可用的网络、凭据和兼容的依赖。
Windows 防火墙可能提示是否允许网络访问，请按自己的部署需要选择。

关闭窗口会保留托盘和后台任务，再次打开 EXE 会回到现有窗口。
需要结束应用时，从托盘菜单选择退出。
Win7 版不会从普通 Windows 更新渠道自动升级，避免覆盖 Win7 配套运行时。

本版范围为桌面壳及 Go + Codex。
DSH/Node 引擎单列适配，不包含在本次通过结论中。
